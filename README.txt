한국 주식 조건검색 스크리너 (KOSPI/KOSDAQ)
================================================

데이터 출처: 네이버금융(무료, 로그인/API키 불필요)
 - 전종목 시가총액/거래량/등락률: 네이버금융 시가총액 페이지
 - 종목별 과거 시세(종가/누적등락률/상승일수 계산용): 네이버금융 개별종목 시세
 - 테마 매칭: 네이버금융 테마 페이지

결과는 엑셀 파일(.xlsx)로 저장되고, 완료되면 자동으로 엑셀에서 열려서
표로 바로 볼 수 있습니다. 헤더는 굵게, 상승/이익은 빨강, 하락/손실은
파랑으로 색이 입혀지고 열 너비도 자동으로 맞춰집니다.
(자동으로 안 열게 하려면 --no-open 옵션. 엑셀(openpyxl)이 없으면 CSV로 대신 저장)

모든 결과 표의 첫 컬럼은 "조회일자"(조회한 날짜, 예: 2026-08-11)입니다.
1번~8번 메뉴, 명령어 실행 어디서든 동일하게 적용됩니다.

같은 이름(예: result_기본스크리닝.xlsx)으로 여러 번 실행하면 파일을
덮어쓰지 않고, 실행 시각으로 이름 붙인 새 시트를 그 파일 안에 계속
추가합니다 (예: 시트 "2026-08-11_143205", "2026-08-11_150130", ...).
엑셀 하단 시트 탭을 눌러 과거 조회 이력을 그대로 다시 볼 수 있고,
매입가로 조회했던 시트는 그 안의 손익 그래프까지 그대로 남아있습니다.

[1] 설치 (최초 1회)
--------------------
1) 파이썬이 설치되어 있어야 합니다 (3.9 이상, 3.14 확인됨).
2) 이 폴더에서 명령 프롬프트/PowerShell을 열고:

   python -m venv venv
   venv\Scripts\pip install -r requirements.txt

   (venv 없이 바로 설치해도 됩니다: pip install -r requirements.txt
    단, 최근 setuptools(81+)가 pykrx가 필요로 하는 pkg_resources를 제거해서
    requirements.txt에 setuptools<81 을 같이 명시해 두었습니다.)

[2] 실행
--------
가장 쉬운 방법: run.bat 파일을 더블클릭하면 메뉴가 뜹니다.
  1) 관심종목 조회  2) 기본 스크리닝  3) 낙폭과대주  4) 상승세 지속 종목
  5) 테마주 검색   6) 특정 종목 조회  7) 직접 옵션 입력  8) 종목 검색
  9) 통합 조회     0) 종료
번호를 입력하고 Enter만 누르면 됩니다. (run.bat 은 내부적으로 menu.py 를 실행합니다)

1번은 종목을 직접 입력할 수 있습니다 (콤마로 여러 개, 예: 006400,삼성전자).
아무것도 입력하지 않고 그냥 Enter를 누르면 관심종목.txt 파일 내용을
대신 사용합니다. 파일은 기본적으로 비어있으니, 자주 보는 종목을 미리
저장해두고 싶으면 관심종목.txt를 열어 추가해두세요.

1번, 6번, 8번은 종목 조회 후 매입가를 물어봅니다. 매입가를 입력하면(그냥
Enter로 건너뛸 수도 있음) 내가 가진 종목이 지금 얼마 벌었는지/잃었는지
손익표로 바로 보여줍니다. 8번은 정확한 종목명을 몰라도 일부 글자로
검색해서 여러 종목의 손익을 한 번에 볼 수 있습니다 (예: "삼성" 검색 후
매입가 입력).

9번(통합 조회)은 테마주 위주의 통합 조회입니다. 테마 키워드를 콤마로
여러 개 입력하면(예: 2차전지,로봇,반도체) 테마별로 각각 시트를 따로
만듭니다 ("테마_2차전지", "테마_로봇", "테마_반도체", ...) - 테마마다
결과를 비교해서 보기 좋습니다. 관심종목/종목검색/종목조회는 선택
사항으로, 필요하면 추가로 입력하고 필요 없으면 Enter로 건너뛰면 됩니다.
전부 하나의 엑셀 파일에 시트별로 담기고, 다 끝나면 그 파일 하나만
자동으로 엽니다.
매입가를 입력하면 관심종목/종목검색/종목조회 시트에는 손익표+차트가
같이 들어갑니다 (테마주는 종목이 많아 매입가를 적용하지 않습니다).
테마 정보(약 250개+ 페이지)는 같은 실행 안에서는 한 번만 가져와서
재사용하므로, 테마를 여러 개 넣어도 두 번째 테마부터는 훨씬 빠릅니다.

만약 창이 뜨자마자 바로 닫혀버린다면 파이썬이 PATH에 없거나 설치가
안 된 것입니다. run.bat이 이 경우 오류 메시지를 띄우고 창을 유지하도록
되어 있으니, 뜨는 메시지를 확인해 파이썬 설치 여부를 점검해 주세요.

[1-1] 휴대폰 앱처럼 사용하기 (모바일 웹앱)
--------------------------------------------
run_mobile.bat 을 더블클릭하면:
  1) 이 PC에서 웹서버가 뜨고
  2) Cloudflare 터널이 인터넷에 공개 접속 주소(https://xxxxx.trycloudflare.com)를
     만들고
  3) 주소가 만들어지자마자 그 주소를 담은 QR코드 이미지가 자동으로 열립니다
     ("접속주소_QR코드.png" 파일).

이 QR코드를 휴대폰 카메라(또는 카메라 앱의 QR 스캔 기능)로 비추면
주소를 직접 타이핑하지 않고 바로 접속됩니다. 주소를 직접 입력하고
싶다면 창에 표시되는 https://...trycloudflare.com 텍스트를 그대로
입력해도 됩니다. Wi-Fi든 데이터망이든 어디서든 접속됩니다.
브라우저 메뉴에서 "홈 화면에 추가"를 하면 아이콘이 생겨서 앱처럼 쓸 수 있습니다.

* 주소는 실행할 때마다 새로 생기고, QR코드도 그때마다 새로 만들어집니다.
  예전에 스캔했던 QR코드나 예전에 받은 주소는 그 실행이 끝나면(창을
  닫으면) 더 이상 작동하지 않습니다. 다시 접속하려면 run_mobile.bat을
  새로 실행해서 나오는 새 QR코드를 다시 스캔하세요.
* 주소가 막 만들어진 직후에는 전 세계 DNS에 퍼지는 데 보통 10~20초,
  느리면 40초 가까이 걸립니다 (Cloudflare도 "만들어지자마자는 안 열릴
  수 있다"고 안내합니다). QR코드를 스캔했는데 "연결할 수 없음"이 뜬다면
  대부분 이 이유이니, 몇 초 기다렸다가 새로고침하거나 다시 스캔해
  보세요. run_mobile.bat 창에도 "확인 완료 - 정상적으로 접속됩니다"라는
  메시지가 뜰 때까지는 PC 쪽에서도 아직 확인이 안 끝난 상태입니다.
* 터널 자체를 만드는 게 실패하면(드묾) 자동으로 몇 초 뒤 다시 시도합니다.
  계속 실패하면 인터넷 연결 상태를 확인해 달라는 안내가 뜹니다.

메뉴 구성은 run.bat과 동일합니다 (관심종목/기본스크리닝/낙폭과대주/상승세/
테마검색/종목조회+손익표/직접옵션/종목검색+손익표/통합조회). 매입가를
입력하면 손익표와 원형 그래프(Chart.js)가 화면에 바로 표시됩니다.
관심종목은 파일 대신 그 자리에서 종목코드/종목명을 직접 입력할 수도
있습니다. 통합조회(테마 위주)는 테마를 콤마로 여러 개 넣으면 화면에
카드가 테마별로 나뉘어 순서대로 나타납니다(엑셀의 시트 여러 개와 같은
역할, 웹에서는 카드로 표시).

주의할 점:
 - 이 PC와 run_mobile.bat 창(하나만 뜸: 서버+터널이 한 창 안에서 같이
   돕니다)이 켜져 있어야 접속됩니다. 창을 닫거나 PC를 끄면 그 순간부터
   접속이 안 됩니다.
 - 매번 실행할 때마다 주소(https://...trycloudflare.com)가 바뀌고,
   PC가 꺼져 있으면 아예 접속이 안 됩니다. PC 없이 24시간 고정 주소로
   쓰고 싶다면 "클라우드배포_가이드.txt"를 참고하세요 (무료 호스팅,
   배포 파일은 이미 준비되어 있고 계정 가입만 직접 하시면 됩니다).
 - 처음 실행하면 Windows 방화벽이 "Python이 네트워크에 접근하려고 합니다"
   라고 물어볼 수 있습니다 -> "허용"을 눌러주세요.
 - 같은 Wi-Fi 안에서만 쓸 거면 터널 없이도 됩니다: run_mobile.bat 대신
   webapp 폴더에서 "python app.py" 실행 후, 폰에서 http://<PC의 사설 IP>:5000
   으로 접속하면 됩니다. (PC 사설 IP는 cmd에서 ipconfig 로 확인)
 - 이 웹앱에는 로그인/비밀번호가 없습니다. 터널이 켜져 있는 동안은 그
   https://...trycloudflare.com 주소를 아는 사람 누구나 접속할 수 있으니
   주소를 다른 사람과 공유하지 마세요. 매입가/수량 등은 서버에 저장되지
   않고 조회할 때마다 그 화면에만 표시됩니다 (관심종목.txt만 파일로 저장됨).

명령어로 직접 실행하고 싶다면:
   python stock_screener.py [옵션들]

venv를 만들었다면:
   venv\Scripts\python stock_screener.py [옵션들]

[2-1] 관심종목.txt (선택 사항 - 내용 추가 가능한 공간)
--------------------------------------------------------
기본적으로 비어있는 파일입니다. run.bat의 "1) 관심종목 조회"에서
매번 종목을 직접 입력해도 되고, 자주 보는 종목을 매번 타이핑하기
귀찮으면 이 파일에 미리 적어두고 그냥 Enter로 불러와도 됩니다.

이 폴더의 "관심종목.txt" 파일에 원하는 종목코드(6자리) 또는 종목명을
한 줄에 하나씩 적어두면, run.bat의 "1) 관심종목 조회"에서 입력 없이
Enter만 누르거나 --watchlist 옵션으로 한 번에 모아서 조회할 수 있습니다.
'#' 뒤는 주석이므로 메모를 남겨도 됩니다. 자유롭게 추가/삭제하세요.

예)
006400   # 삼성SDI
005930   # 삼성전자

명령어: python stock_screener.py --watchlist 관심종목.txt

[3] 조건(옵션) 설명
--------------------
--market-cap-min      시가총액 하한 (억원 단위). 예: 1000 -> 시총 1000억 이상만
--volume-min          당일 거래량 하한 (주). 예: 500000 -> 50만주 이상 거래된 종목만
--cum-decline-min     누적하락률 하한 (%). 예: 20 -> 최근 N거래일간 20% 이상 하락한 종목만
--up-days-min         기간 내 상승일수 하한. 예: 4 -> 최근 N거래일 중 상승 마감한 날이 4일 이상
--consecutive-up-min  최근 "연속" 상승일수 하한. 예: 3 -> 최근 3거래일 연속 상승 마감
--theme-keyword       이슈테마주 필터. 예: "2차전지,로봇" -> 해당 테마에 속한 종목만
                       (네이버금융 테마 페이지 기준. 테마가 약 250개+ 있어 수 분 소요될 수 있음)
--period              위 조건들의 계산 기간(거래일 수), 기본값 20
--min-data-days       분석하한: 계산 기간 동안의 시세 데이터가 이 값 미만인 종목은 제외
                       (신규 상장 등으로 데이터가 부족한 종목 필터링용). 기본값 = --period
--market              KOSPI / KOSDAQ / ALL (기본값 ALL)
--code                특정 종목만 조회 (종목코드, 콤마로 복수 가능). 예: 006400 (삼성SDI)
                       지정 시 시총/거래량 하한 필터는 건너뛰고 해당 종목만 계산합니다.
--name                특정 종목만 조회 (종목명, 콤마로 복수 가능, 정확히 일치해야 함). 예: 삼성SDI
--search              종목명/코드에 이 글자가 포함되면 전부 검색 (정확한 이름 몰라도 됨).
                       예: --search 삼성 -> 삼성전자/삼성SDI/삼성물산 등 관련 종목 전부.
                       콤마로 여러 키워드 지정 가능 (OR 조건).
--watchlist           관심종목.txt 같은 파일 경로. 파일에 적힌 종목들을 한 번에 조회
--out                 결과 엑셀 파일명 (기본값 screener_result.xlsx, 확장자는 자동으로 .xlsx로 맞춰짐)
--no-open             결과 엑셀 파일을 자동으로 열지 않음 (기본값: 완료 후 자동으로 엶)
--buy-price           평균단가(매입 평균단가). 지정하면 표가 증권사 "보유잔고" 화면 형태로 바뀝니다.
--quantity            보유잔고(수량). --buy-price와 함께 지정. 생략하면 1주로 계산.
--combined            테마주 위주 통합 조회. --theme-keyword에 콤마로 여러 테마를 넣으면
                       테마별로 시트를 따로 만듭니다 (테마_2차전지, 테마_로봇, ...).
                       --wl-input/--search-kw/--lookup은 선택 사항(관심종목/종목검색/종목조회
                       추가). 전부 한 엑셀 파일에 시트로 저장하고 끝나면 그 파일만 자동으로 엶.
--wl-input            (--combined 전용) 관심종목 직접 입력. 생략하면 --watchlist 파일 사용.
--search-kw           (--combined 전용) 종목검색 키워드
--lookup              (--combined 전용) 종목조회 종목코드/종목명

■ --buy-price 없이 조회할 때 (일반 스크리닝/종목 조회):
결과 표 컬럼: 종목코드, 종목명, 현재가, 종가, 등락률(%), 거래량, (테마 지정 시)테마
(시가총액/기간누적등락률/기간상승일수/연속상승일수는 필터링에는 여전히 쓰이지만
 표에는 표시하지 않습니다. --cum-decline-min 등 조건 필터는 그대로 동작합니다.)

■ --buy-price 지정 시 (보유잔고/손익 조회):
결과 표 컬럼: 종목코드, 종목명, 평가손익, 손익률(%), 매입금, 평가금,
             매도가능, 평균단가, 보유잔고, 현재가
* 매도가능은 대주/담보 등으로 묶인 수량을 추적하지 않으므로 보유잔고와 항상 같습니다.
* 엑셀 시트 안에 원형(파이) 그래프가 2개 자동으로 삽입됩니다:
  1) 평가금 비중 — 종목별 현재 평가금액의 비율
  2) 평가손익 비중 — 이익 종목은 빨강, 손실 종목은 파랑 조각으로 표시
  각 조각에는 종목명·금액·비율이 가로 방향 글자로 표시됩니다(세로로 눕지 않음).
* 현재가는 네이버금융 시가총액 페이지 기준 최신 가격(장중이면 실시간에 가까움)입니다.

[4] 사용 예시
--------------
# 시총 1000억 이상 + 거래량 50만주 이상
python stock_screener.py --market-cap-min 1000 --volume-min 500000

# 최근 20거래일간 20% 이상 하락한 종목 (낙폭과대주)
python stock_screener.py --cum-decline-min 20

# 최근 20거래일 중 상승일이 12일 이상 (강세 지속 종목)
python stock_screener.py --up-days-min 12

# 최근 3거래일 연속 상승
python stock_screener.py --consecutive-up-min 3

# 2차전지/로봇 테마 + 시총 500억 이상
python stock_screener.py --theme-keyword 2차전지,로봇 --market-cap-min 500

# 여러 조건 동시 적용
python stock_screener.py --market-cap-min 1000 --volume-min 300000 --cum-decline-min 15 --up-days-min 10 --period 20

# 삼성SDI만 개별 조회 (시총/거래량 필터 없이 지표만 확인)
python stock_screener.py --code 006400
python stock_screener.py --name 삼성SDI --period 20

# 정확한 종목명을 모를 때 이름 일부로 검색
python stock_screener.py --search 삼성
python stock_screener.py --search SK,카카오

# 삼성SDI를 40만원에 10주 매입했을 때 현재 손익 확인 (엑셀에 손익 막대그래프까지 자동 삽입)
python stock_screener.py --code 006400 --buy-price 400000 --quantity 10

# 테마 3개를 각각 시트로 나눠 한 엑셀에 (테마_2차전지, 테마_로봇, 테마_반도체)
python stock_screener.py --combined --theme-keyword 2차전지,로봇,반도체

# 위에 관심종목/종목검색/종목조회까지 추가
python stock_screener.py --combined --theme-keyword 2차전지,로봇 --wl-input 006400,005930 --search-kw 삼성 --lookup 000660

[5] 참고 / 한계
-----------------
- 조건이 많을수록(특히 상승일수/연속상승일/누적하락) 후보 종목마다 개별 조회를
  하므로 시간이 걸립니다. 먼저 --market-cap-min, --volume-min 으로 1차로 후보를
  줄인 뒤 나머지 조건을 추가하는 것을 권장합니다.
- 테마 정보는 네이버금융의 비공식 페이지 구조를 파싱한 것이라, 네이버가 페이지를
  개편하면 동작하지 않을 수 있습니다. 이 경우 --theme-keyword 없이 나머지
  조건만으로 사용하세요.
- 실행 중 "KRX 로그인 실패..." 메시지가 보일 수 있는데, 이는 사용하지 않는
  기능(KRX 공식 일괄조회)의 안내 메시지로 결과에는 영향이 없습니다. 무시해도 됩니다.
- 이 프로그램은 종목을 "필터링"만 해줄 뿐, 매수/매도를 판단하거나 추천하지
  않습니다. 투자 판단과 책임은 본인에게 있습니다.
