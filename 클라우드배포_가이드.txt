PC 없이 24시간 접속되는 서버 만들기 (무료 호스팅 배포 가이드)
====================================================================

지금까지 만든 run_mobile.bat 방식은 "내 PC + 터널"이라 PC를 꺼두면
접속이 끊깁니다. PC 없이 폰 브라우저 접속만으로 쓰려면 어딘가의
서버(호스팅)에 이 프로그램을 올려둬야 합니다.

무료로 가능한 방법을 준비해 뒀습니다. 아래 순서대로만 따라하시면 됩니다.
계정 만드는 부분(2군데)은 보안상 본인이 직접 하셔야 해서, 제가 대신
할 수 없는 부분만 표시해 뒀습니다.

이미 준비해 둔 배포용 파일 (이 폴더 안에 있음):
 - requirements.txt   : 필요한 패키지 목록 (gunicorn 추가해 둠)
 - Procfile            : 서버 실행 명령
 - render.yaml          : Render.com이 자동으로 설정을 읽어가는 파일
 - .gitignore           : 업로드할 필요 없는 파일 제외 목록


[1단계] GitHub에 코드 올리기
--------------------------------
GitHub는 코드를 저장해두는 곳입니다. Render가 여기서 코드를 가져갑니다.

1) 계정이 없다면: https://github.com/signup 에서 무료로 가입 (본인이 직접)
2) 로그인 후 오른쪽 위 "+" -> "New repository" 클릭
3) Repository name에 아무 이름 (예: stock-screener) 입력
4) Public / Private 아무거나 선택해도 됩니다 (Private 추천, 어차피 다음
   단계에서 Render가 계정 연동으로 접근하므로 상관없음)
5) "Create repository" 클릭
6) 만들어진 빈 저장소 화면에서 "uploading an existing file" 링크 클릭
   (또는 상단의 "Add file" -> "Upload files")
7) 이 폴더(주식프로그램) 안의 파일과 폴더를 전부 마우스로 끌어다 놓기
   - webapp 폴더(안의 app.py, templates, static 전부 포함)
   - stock_screener.py
   - requirements.txt, Procfile, render.yaml, .gitignore
   - 관심종목.txt
   - (menu.py, run.bat, run_mobile.bat/.py는 안 올려도 되지만 올려도 무방)
   - result_*.xlsx 같은 결과 파일은 안 올려도 됩니다
8) 아래 "Commit changes" 초록 버튼 클릭 -> 업로드 완료

* 폴더째로 끌어다 놓으면 GitHub 웹 화면이 폴더 구조를 그대로 유지해
  줍니다 (webapp/app.py 처럼). 혹시 폴더 구조가 깨져 보이면, webapp
  폴더를 먼저 통째로 끌어다 놓고, 나머지 파일들을 이어서 끌어다 놓으세요.


[2단계] Render.com 가입하고 배포하기
--------------------------------------
Render가 GitHub의 코드를 가져다가 실제로 서버를 돌려줍니다. 무료
플랜은 신용카드 등록이 필요 없습니다.

1) https://render.com 접속 -> "Get Started" -> "Sign up with GitHub"
   (본인이 직접 가입 - GitHub 계정으로 바로 가입하면 편합니다)
2) GitHub 연동 권한 요청이 뜨면 방금 만든 저장소만 선택하거나 전체 허용
3) Render 대시보드에서 "New +" -> "Blueprint" 클릭
4) 방금 만든 저장소(stock-screener)를 선택 -> "Connect"
5) render.yaml을 자동으로 읽어서 서비스 설정이 미리 채워집니다.
   그대로 "Apply" 또는 "Create New Resources" 클릭
6) 빌드가 시작됩니다 (보통 2~5분 정도 걸림). 로그 화면에 설치 과정이
   쭉 나오고, 끝나면 "Live"로 바뀝니다.
7) 화면 위쪽에 https://stock-screener-xxxx.onrender.com 같은 주소가
   보입니다. 이게 이제부터 계속 쓸 고정 주소입니다.


[3단계] 폰에서 접속
----------------------
그 https://...onrender.com 주소를 폰 브라우저에 입력하거나 즐겨찾기/
홈 화면에 추가해 두세요. PC를 꺼도, run_mobile.bat을 실행하지 않아도
이 주소로 항상 접속됩니다.


참고 / 한계
-------------
* 무료 플랜은 15분 동안 아무도 접속을 안 하면 서버가 잠깐 잠듭니다.
  그 상태에서 오랜만에 접속하면 첫 화면이 뜨는 데 30~50초 정도 걸릴
  수 있습니다(그 다음부터는 빠릅니다). 유료 플랜으로 바꾸면 항상
  깨어있게 할 수 있지만, 지금은 무료로 충분합니다.
* 관심종목.txt는 웹 화면에서 수정/저장해도, 나중에 GitHub에 새로
  파일을 다시 올려서 재배포하면(코드 업데이트) 그 수정 내용이 초기화될
  수 있습니다. 자주 쓰는 종목은 1단계에서 관심종목.txt 파일 자체를
  미리 채워서 올려두는 걸 추천합니다.
* 나중에 코드를 수정하고 싶으면: GitHub 저장소에서 파일을 다시
  업로드(덮어쓰기)하면 Render가 자동으로 새로 배포합니다.
* 이 주소는 로그인이 없어서 아는 사람은 누구나 접속할 수 있습니다.
  민감한 정보를 넣지 마시고, 필요하면 저에게 로그인 기능 추가를
  요청하실 수도 있습니다.
